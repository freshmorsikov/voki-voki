# Инструкции для работы с проектом

- «Воки-воки» — статическая браузерная игра без сборки. Исходные файлы и публикуемый сайт находятся в `dist/`.
- Для локальной проверки запустите `python3 -m http.server 8000 --directory dist` и откройте `http://localhost:8000`. Проверяйте затронутые страницы и игровые сценарии в браузере.
- Сохраняйте совместимость с GitHub Pages: используйте относительные пути к ресурсам. На GitHub Pages публикуется содержимое `dist/`.
- При изменении карточек соблюдайте структуру существующих JSON-файлов и рекомендации из `rules.md`; проверяйте корректность JSON.
- Следуйте существующему стилю кода и интерфейса. Не добавляйте зависимости и этап сборки без необходимости.
