# Воки-воки

Браузерная игра для компании: объясняйте слова, показывайте их жестами или рисуйте, а друзья пусть угадывают. Выбирайте любимый мир и соревнуйтесь командами.

## Возможности

- Тематические наборы по «Гарри Поттеру» и «Игре престолов».
- Команды и игроки, подсчёт очков и очередность ходов.
- Виртуальный кубик, карточки с разными типами заданий и сложные задания.
- Сохранение игры в браузере.

## Структура проекта

```text
dist/                  Готовый статический сайт
  index.html           Выбор мира
  new-game.html, .js   Настройка команд и игроков
  game.html, app.js    Игровой экран и логика
  home.css, styles.css Стили страниц
  images/              Логотип
  harry-potter/        Команды и карточки по «Гарри Поттеру»
  game-of-thrones/     Команды и карточки по «Игре престолов»
rules.md               Рекомендации по подбору слов для карточек
.github/workflows/     Публикация на GitHub Pages
```

## Быстрый старт

Из корня проекта запустите локальный сервер:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000` в браузере. Сервер нужен для загрузки JSON-файлов с заданиями и командами.
